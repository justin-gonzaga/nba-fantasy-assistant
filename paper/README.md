# Research Paper: living plan

_Style: IEEE conference, two-column, **6–7 pages** + references · Build: LaTeX (`paper/main.tex`), with the PDF built in CI · Goal: arXiv preprint + portfolio_

**Working title**: *Point-in-Time Decision Support for Fantasy Basketball: A Format-Aware Simulation and Leakage-Free Evaluation Framework*

## Rules
1. **Every empirical claim cites evidence**: a committed evaluation report (`docs/evaluation/reports/…`) or an MLflow run ID. There are no placeholder numbers in the compiled PDF. Unfinished results are written as `\todo{}` and are visible in drafts only.
2. **Figures and tables are generated by scripts** (`paper/figures/make_*.py` → `just paper-figures`) from real results, never drawn by hand.
3. **Citations come from `docs/research/ml-literature-review.md`** (`[R-xx]` → `references.bib`), and only entries that have actually been read (RSCH-001).
4. **Standard academic phrasing and IEEE structure.** Contributions are stated as a bulleted list in the introduction, limitations are stated plainly, and there is no marketing language.
5. The paper is updated **as the work happens**: when a task produces paper-relevant material (a method, a result, or a figure), its notes go in the section log below.

## Candidate contributions (to be confirmed by results)
1. A **point-in-time data architecture** for fantasy sports decision support, enabling leakage-free historical replay.
2. A **format-agnostic decision engine**: one simulation core with pluggable objectives for all five Yahoo NBA scoring formats.
3. An **evaluation protocol** for recommendation quality, using counterfactual scoring with realised box scores and paired significance testing.
4. An empirical comparison of statistical and ML projection components under this protocol.
